# Fresco component guidance

Practical guidance for building clear, consistent and accessible Oxford University pages in Fresco.

This guide covers three levels:

- **Components** — individual content building blocks
- **Section templates (slices)** — tested combinations of components that create a useful section or group of rows
- **Page templates** — starter structures for common page types

The aim is to help editors construct effective pages without needing to design every page from scratch. The patterns should support user needs, Oxford identity, accessibility, responsive layouts and consistent publishing practice.
