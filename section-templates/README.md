# Section-template library

Section templates — also called slices — are pre-arranged groups of components that perform one recognisable job within a page. They reduce layout decisions for editors while keeping pages flexible.

## Initial shopping list

| Template | Primary job |
| --- | --- |
| [Introduction and next steps](introduction-and-next-steps.md) | Orient the visitor and expose the main routes or actions |
| [Featured content](featured-content.md) | Give one item deliberate prominence |
| [Card grid](card-grid.md) | Present a small set of genuinely parallel choices |
| [Image and text feature](image-and-text-feature.md) | Pair explanatory content with a purposeful image |
| [Key information](key-information.md) | Surface concise facts, deadlines or practical details |
| [Contact and related links](contact-and-related-links.md) | Give onward routes and a clear point of contact |

Further candidates to assess include latest news, upcoming events, people highlights, statistics, testimonials, downloads and calls to action.

Each template needs a defined purpose, content rules, responsive behaviour and an example. Use the [section-template specification](section-template-specification.md) when adding one.
