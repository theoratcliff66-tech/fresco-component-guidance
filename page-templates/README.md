# Page-template library

Page templates are starter kits for recurring page types. They provide a sensible hierarchy and sequence while allowing editors to remove sections that do not support the user need.

## Initial shopping list

| Template | Primary job |
| --- | --- |
| [Standard content page](standard-content-page.md) | Explain one topic clearly |
| [Landing page](landing-page.md) | Help visitors choose between major routes |
| [People listing](people-listing.md) | Find and compare people |
| [Profile page](profile-page.md) | Understand one person's role and work |
| [News or article page](news-or-article-page.md) | Read a dated editorial item |
| [Event page](event-page.md) | Decide whether and how to attend |
| [Course or programme page](course-or-programme-page.md) | Evaluate a course or programme |
| [Research project page](research-project-page.md) | Understand a project, its people and outputs |
| [Download or software page](download-or-software-page.md) | Get the right version and understand conditions |
| [Contact page](contact-page.md) | Find the correct route for help |

Use the [page-template specification](page-template-specification.md) for new entries.
