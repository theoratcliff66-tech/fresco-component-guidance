# Component guidance

This section will document Fresco's individual building blocks. Guidance should use the actual component names shown in the CMS and include screenshots once the inventory has been verified.

## Initial component guidance backlog

- Page heading and introduction
- Hero or banner variants
- Rich text
- Image
- Image gallery
- Video embed and consent placeholder
- Cards and card grids
- Call to action
- Link list
- Accordion
- Tabs, if available
- Quote or testimonial
- Statistics or key facts
- Person or profile card
- Contact details
- Download or document link
- Tables
- Related content
- News and event listings
- Forms and embeds

Use the [component guidance template](component-guidance-template.md) for every entry. The backlog is deliberately provisional until it is reconciled with the live Fresco component inventory.
