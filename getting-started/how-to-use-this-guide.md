# How to use this guide

Start with the type of page the visitor needs, not with a component.

1. Choose the closest [page template](../page-templates/README.md).
2. Keep the parts that support the page's main user need.
3. Add a tested [section template](../section-templates/README.md) where necessary.
4. Use the [component guidance](../components/README.md) to write and configure each building block.
5. Preview the page at desktop and mobile widths.
6. Check headings, links, images, accessibility and the primary action before publishing.

Templates are starter kits, not compulsory finished layouts. Remove sections that do not have a clear job. Do not add content merely to fill a template.

## Terminology

| Term | Meaning |
| --- | --- |
| Component | One configurable building block, such as a card, image, accordion or call to action |
| Section template or slice | A reusable combination of components that performs one content job |
| Page template | A starter arrangement of sections for a common page type |
